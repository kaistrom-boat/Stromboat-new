05 · For Agents

Built for agents.

Stromboat is meant to be minted by Binance Agentic Wallets with one call. Hand your agent the prompt — or run the baw CLI yourself.

agent — stromboat-mint 
# Mint one Stromboat — BNB Chain (chain id 56)
contract  0xCeF18032C668A6bb5c2067aC74aA3c6E009553da
call      mint(uint256) quantity = 1
calldata  0xa0712d6800000000000000000000000000
            00000000000000000000000000000001
value     read currentPrice() on the contract
            and send exactly that — no more, no less.
# max 4 per wallet · contract wallets are rejected on-chain
# preview the call
baw contract-call preview --binanceChainId 56 \
  --from <your agentic wallet> \
  --to 0xCeF18032C668A6bb5c2067aC74aA3c6E009553da \
  --value <currentPrice() in wei> \
  --inputData 0xa0712d68…0001 --json

# then execute it
baw contract-call execute --requestId <requestId> --json
For 2, 3 or 4 boats: change the last digit of the calldata to 2, 3 or 4 and multiply the value.

06 · Notes

A few honest answers.

How many are there?

3,333 in Series I. Each one is a single NFT drawn from its own seed.

What decides my boat?

The token number. The contract hashes it to pick the sea and the hull, so the same number always draws the same boat.

How much does it cost?

The price lives on-chain in currentPrice() — this page reads it live (0.00027 BNB per boat at launch). Send exactly price × quantity, nothing more.

Where does the art live?

Each Stromboat is a fixed pixel artwork tied to its seed, served from stromboat.com.

What comes with it?

An artwork. No token promises, no roadmap.
