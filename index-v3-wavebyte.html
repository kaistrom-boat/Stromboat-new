LEVEL 06 · AGENT MODE

BUILT FOR AGENTS.

WAVEBYTE is meant to be minted by Binance Agentic Wallets with one call. Hand your agent the prompt — or run the baw CLI yourself.

agent — wavebyte-mint 
# Mint one WAVEBYTE rider — BNB Chain (chain id 56)
contract  0xCeF18032C668A6bb5c2067aC74aA3c6E009553da
call      mint(uint256) quantity = 1
calldata  0xa0712d6800000000000000000000000000
            00000000000000000000000000000001
value     read currentPrice() on the contract
            and send exactly that — no more, no less.
# max 4 per wallet · contract wallets are rejected on-chain
# preview the call
baw contract-call preview --binanceChainId 56 \
  --from <your agentic wallet> \
  --to 0xCeF18032C668A6bb5c2067aC74aA3c6E009553da \
  --value <currentPrice() in wei> \
  --inputData 0xa0712d68…0001 --json

# then execute it
baw contract-call execute --requestId <requestId> --json
For 2, 3 or 4 riders: change the last digit of the calldata to 2, 3 or 4 and multiply the value.

LEVEL 07 · NOTES

A FEW HONEST ANSWERS.

HOW MANY ARE THERE?

3,333 in Series 01. Each one is a single NFT drawn from its own seed.

WHAT DECIDES MY RIDER?

The token number. It is hashed to pick the class, zone, wave and storm — the same number always draws the same rider. Try the Seed Lab above: it runs on the same principle.

HOW MUCH DOES IT COST?

The price lives on-chain in currentPrice() — this page reads it live (0.00027 BNB per rider at launch). Send exactly price × quantity, nothing more.

IS THIS STROMBOAT?

No — WAVEBYTE is its own world, its own art and its own name. It runs on the stromboat.com domain and launches on the same proven mint contract logic: one mint(uint256) call, live on-chain price, max 4 per wallet, built for Agentic Wallets.

WHAT COMES WITH IT?

An artwork. No token promises, no roadmap.
